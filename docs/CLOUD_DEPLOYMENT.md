# Eyen cloud deployment (Render + Neon)

This setup is intentionally separate from Supabase and from the Bunyan project.

## Components
- Render Web Service runs the existing Node.js/Express API from the `server/` directory.
- Neon provides managed PostgreSQL on its independent Free plan.
- Android clients will use the Render HTTPS service URL after the first successful deployment.

## 1. Create the Neon database
1. Create a Neon account at https://neon.tech and create a project named `eyen`.
2. Choose a region close to Render Frankfurt if available.
3. Copy the pooled connection string for the database.
4. In the Neon SQL Editor, run the contents of `server/db/001_pairing.sql`.
5. Keep the connection string private. Do not commit it or put it in Android.

Neon's Free plan has quotas and can suspend compute after monthly limits; check the current plan limits before relying on it for continuous production use.

## 2. Deploy the API on Render
1. Create/sign in at https://render.com.
2. Choose **New > Blueprint** and connect `emadmedo19/eyen-parental-control`.
3. Select branch `feature/device-pairing` (do not select or modify `main`).
4. Render should detect the root `render.yaml` and create the `eyen-api` web service.
5. When prompted, set `DATABASE_URL` to the Neon pooled connection string. `TOKEN_PEPPER` is generated by the blueprint; never expose it.
6. Wait for deployment to finish. Verify the service URL by opening `https://YOUR-RENDER-SERVICE.onrender.com/health`; expected JSON includes `"ok":true`.

## 3. Free-tier caveats
Render Free web services sleep after 15 minutes without inbound traffic and may take about a minute to wake. They are suitable for initial pairing tests, not dependable always-on parental monitoring. Neon Free also has compute and storage quotas. Before enabling continuous monitoring or live sessions, choose an always-on paid host or a self-hosted VPS and set a spending limit.

## 4. Android API URL
Only after the health check succeeds, replace the placeholder API origin in both:
- `android/parent/src/main/java/app/eyen/parent/ApiClient.kt`
- `android/child/src/main/java/app/eyen/child/ApiClient.kt`

Use the Render HTTPS origin without a trailing slash, then build and test both APKs. Do not paste database credentials or `TOKEN_PEPPER` into Android code.
